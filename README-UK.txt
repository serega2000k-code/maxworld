MAXWORLD v2.1 — покращена графіка та рух

У цій версії оновлено наявний проєкт, а не створено нову гру.

Зміни:
- підвищено чіткість процедурних текстур трави, землі, асфальту та фасадів;
- покращено налаштування експозиції та динамічного оновлення тіней;
- асфальт і тротуари мають окремі матеріали;
- швидкість руху підвищена, частота кроків і розмах рук/ніг узгоджені зі швидкістю;
- камера швидше та плавніше стежить за персонажем;
- взуття прикріплене до рухомих ніг, тож ноги й взуття рухаються разом;
- монети зменшені, мають металевий обідок і менший радіус збору.

Розгортання на Render:
1. Завантаж вміст папки mw у корінь GitHub-репозиторію або встанови Root Directory = mw, якщо папка mw лежить у корені репозиторію.
2. Build Command: npm install
3. Start Command: npm start
4. Для постійного збереження прогресу налаштуй DATABASE_URL та DEVELOPER_CODE в Environment.

Перевірка: виконано node --check для клієнтського JavaScript і server.js. Реальний браузерний тест на Render ще потрібен. Це оновлення графіки та керування, а не завершена AAA-гра; для фотореалістичних моделей потрібні спеціально створені/ліцензовані 3D-ресурси.
