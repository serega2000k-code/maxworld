MAXWORLD v5.1 — мобільне керування та встановлення на Android/iOS

НОВЕ У v5.0
- Додано чотири місії: зібрати 10 монет, проїхати 250 м, відвідати центр міста, побудувати власний будинок.
- Кожна місія має окрему нагороду монетами та XP; нагороду можна забрати один раз.
- Прогрес місій зберігається у локальному сховищі разом з офлайн-прогресом.
- Додано кнопку «ГРАТИ ОФЛАЙН»: не вимагає реєстрації або сервера.
- Додано PWA manifest та Service Worker: після першого повного онлайн-завантаження браузер кешує гру й Three.js для подальшого запуску без інтернету.
- Додано desktop wrapper на Electron та конфігурацію інсталятора Windows x64/ia32 (NSIS), ярлики робочого столу й меню Пуск.
- Для онлайн-акаунта можна вказати адресу сервера у формі входу; API endpoint зберігається на цьому пристрої.
- Додано базову онлайн-присутність: авторизовані гравці передають координати на сервер приблизно раз на секунду та бачать інших онлайн-гравців. Це базова синхронізація позицій, без голосового чату, бойової системи чи синхронізації фізики авто.

ЯК ГРАТИ ОФЛАЙН
1. Відкрий гру після першого онлайн-завантаження, щоб кеш завантажив 3D-бібліотеку.
2. Натисни «ГРАТИ ОФЛАЙН».
3. Прогрес зберігається на цьому пристрої. Онлайн-синхронізація офлайн-профілю автоматично не відбувається.

ВСТАНОВЛЕННЯ ЯК PWA (Chrome/Edge)
1. Розмісти public/ на HTTPS-хостингу.
2. Відкрий адресу гри у Chrome/Edge, дочекайся повного завантаження 3D-сцени.
3. У меню браузера обери «Встановити MAXWORLD» / «Install app».
4. Після першого кешування гра запускається з ярлика; для першого завантаження потрібен інтернет.

СТВОРЕННЯ WINDOWS EXE/SETUP
1. Потрібен комп'ютер з Node.js та npm.
2. Розпакуй архів і запусти build-windows.bat.
3. Інсталятори з'являться у dist: MAXWORLD-Setup-x64.exe та MAXWORLD-Setup-ia32.exe.
4. Electron 22 обрано як старішу гілку для сумісності з Windows 7; реальну сумісність конкретної збірки потрібно перевірити на цільовому ПК.

ОНЛАЙН
- Вкажи HTTPS-адресу розгорнутого MAXWORLD server.js у полі «Адреса онлайн-сервера».
- Сервер має бути доступний з інтернету та підтримувати API цього архіву.
- Офлайн-прогрес локальний; автоматичне об'єднання/синхронізація офлайн і серверного прогресу поки не реалізована.
- Для онлайн-режиму серверні API мають дозволяти CORS з адреси гри. У server.js цього пакета додано CORS headers.

ЗАПУСК СЕРВЕРА ДЛЯ РОЗРОБНИКА
 npm install
 npm start

ПЕРЕВІРКИ
Синтаксис JavaScript перевірено локально. PWA/офлайн кеш перевірено статично; інсталяційний EXE тут не скомпільовано, бо збірка Electron потребує завантаження залежностей через npm і Windows packaging toolchain. Після першого запуску онлайн Three.js зберігається у кеші Service Worker; повністю холодний перший запуск без інтернету не підтримується.

Це все ще розробницький прототип MAXWORLD на Three.js, а не гра рівня GTA San Andreas.


МОБІЛЬНА ВЕРСІЯ v5.1
- Адаптовано інтерфейс для телефонів і планшетів; підтримується вертикальна та горизонтальна орієнтація, для гри рекомендовано горизонтальну.
- Сенсорний джойстик керує рухом і поворотом; свайп по правій частині екрана повертає камеру.
- Кнопки E (взаємодія), стрибок, газ і гальмо; газ/гальмо показуються під час керування автомобілем.
- Додано кнопку встановлення PWA та інструкцію для Android Chrome. На iPhone/iPad: Safari → Поділитися → На початковий екран.
- Додано PNG-іконки 192x192 і 512x512 для Android та оновлено кеш Service Worker.

ВСТАНОВЛЕННЯ НА ANDROID
1. Розгорни public/ на HTTPS-сайті (Service Worker не працює через звичайний HTTP, окрім localhost).
2. Відкрий сайт у Chrome, дочекайся завантаження сцени.
3. Натисни «Встановити MAXWORLD на телефон» або меню Chrome (⋮) → «Встановити застосунок» / «Додати на головний екран».
4. Запускай MAXWORLD з іконки; після першого успішного онлайн-завантаження кеш дозволяє повторний офлайн-запуск.

ВСТАНОВЛЕННЯ НА iPHONE/iPAD
1. Відкрий HTTPS-адресу гри у Safari.
2. Натисни «Поділитися» → «На початковий екран» → «Додати».
3. Запускай з іконки. Перший запуск і завантаження 3D-бібліотеки потребують інтернету.

МОБІЛЬНИЙ APK
У цій збірці реалізовано встановлення як PWA, а не окремий APK. PWA встановлюється без Google Play та без Android Studio. Для підписаного APK/AAB потрібна окрема Android-збірка (наприклад Capacitor) і перевірка на реальному телефоні.

ANDROID APK (ДОДАНО У v5.1)
В архіві є папка android-app — нативний Android Studio-проєкт для створення APK.
Це ще не готовий APK: для його компіляції потрібні Android Studio, Android SDK
та Gradle. Детальна інструкція міститься в android-app/README-ANDROID-UK.txt.
