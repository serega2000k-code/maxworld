MAXWORLD v2.2 MOBILE — версія для телефону

Це мобільно-адаптована версія на основі проєкту MAXWORLD v2.1. Основні серверні функції та структура проєкту збережені.

Що адаптовано для телефону:
- сенсорний віртуальний джойстик із плавним аналоговим рухом;
- свайп правою частиною екрана для повороту камери;
- окремі кнопки стрибка та взаємодії з будинком;
- компактний інтерфейс для портретної й альбомної орієнтації;
- панелі меню, профілю та реєстрації адаптовані до маленького екрана;
- зменшене початкове навантаження на GPU через обмеження pixel ratio;
- обробка зміни орієнтації екрана.

Розгортання на Render:
1. Розпакуй архів.
2. Завантаж вміст папки mw у корінь GitHub-репозиторію або встанови Root Directory = mw, якщо папка mw лежить у корені репозиторію.
3. Build Command: npm install
4. Start Command: npm start
5. Для постійного збереження прогресу налаштуй DATABASE_URL та DEVELOPER_CODE в Environment.

Керування на телефоні:
- лівий джойстик — рух у будь-якому напрямку;
- свайп праворуч від центру — обертання камери;
- кнопка ⬆ — стрибок;
- кнопка E — увійти/вийти з будинку, коли це доступно;
- кнопки ліворуч — профіль, інвентар, магазин, будинок і налаштування.

Перевірка: node --check для клієнтського JavaScript та server.js пройдено. Фізичний тест на Android-браузері та перевірка Render ще потрібні.


Версія 2.4 — міський ескіз: центральний бульвар, скляні хмарочоси, вітрини, дорожня розмітка, вуличні ліхтарі, лавки та автомобілі. Зберігає запуск через кнопку «ГРАТИ», керування ПК/телефон і серверний server.js.


Оновлення v2.6: оптимізовано рендеринг для телефону й ПК, вимкнено дорогі динамічні тіні, зменшено процедурні текстури й кількість дерев/зайвих будівель, додано небесні хмари та читабельні вивіски магазинів. Перевірка JavaScript: node --check пройдена. Реальний Render-деплой необхідно перевірити після завантаження.


Версія 2.7 — візуальне оновлення: менший персонаж і NPC, темніші скляні фасади з деталізованою сіткою вікон, реалістичніші дерева, розмітка переходів та м’якша кінематографічна палітра. Перевірте на Render на ПК і телефоні; фактичний FPS залежить від пристрою.
